--- title: "A basic configuration for automation in biology using Opentrons and ChiBio" excerpt: "Connecting liquid handling, miniature bioreactors and Python to run iterative culture experiments." collection: portfolio image: /assets/images/automated-lab.webp topic: "Lab automation" ---

Opentrons and ChiBio work well together for automating protocols involving starter cultures. This configuration puts four miniature bioreactors inside the deck, leaving space for tubes, plates and tips.

The reactors grow starter cultures in LB medium, which are transferred to a plate where each well contains a different culture medium composition. The results inform the next set of combinations and generate scripts to control the Opentrons robot and ChiBio in the following iteration.

Python coordinates the process, including alerts for system crashes. The experiments take place inside the robot's UV-disinfected deck.
